## Week 3 — Layered Architecture

Start with the [Week 3 README](WEEK3/README.md) for the project structure, business rules, and test commands.

- [Models](WEEK3/lib/model): student, course, and course result data.
- [Service](WEEK3/lib/service/lms_system.dart): LMS operations and validation.
- [Tests](WEEK3/test/lms_system_test.dart): checks for the service operations.

Week 3 is a Dart console-library practice. It does not need a Flutter screen, database, or repository layer.
